# Rachel Pilates - אתר הסטודיו

אתר סטטי (HTML/CSS/JS) בלי שלב בנייה. מיועד לאחסון ב-Cloudflare Pages.

- `config.js` - מספר וואטסאפ, שם היישוב, קישורים לאינסטגרם ולפייסבוק
- `styles.css` - צבעים ופונטים בראש הקובץ (`:root`)
- `index.html` - התוכן
- `images/` - תמונות (לשים כאן ולהפנות מ-index.html)

תצוגה מקומית: לפתוח את `index.html` בדפדפן.
